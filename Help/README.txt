HOW TO RUN
1. Ensure all requirements are installed (see Support/README.txt)
2. Navigate to Source Code/
3. Open any .ipynb file in Jupyter Notebook or VS Code
4. Click "Run All" to execute all cells
5. Each notebook outputs: Accuracy, Precision, Recall, F1-Score, 
   Specificity, Confusion Matrix, ROC curve, and blue-themed charts
6. For the Voting Ensemble notebooks (XGB_RF_SVM_Ensemble/), 
   SHAP feature importance plots are also generated
